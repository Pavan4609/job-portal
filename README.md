# Job Portal

A full-stack Job Portal web application built using Python Flask, MySQL, HTML, CSS and JavaScript.

## Features

### Job Seeker
- Register and Login
- Search Jobs
- Location Search
- Salary Filter
- Job Type Filter
- Experience Filter
- View Job Details
- Apply for Jobs
- Application Tracking
- Save Jobs
- Recommended Jobs
- Profile Management
- Resume Upload
- Change Password
- Forgot Password with OTP

### Employer
- Employer Registration and Login
- Employer Dashboard
- Post Jobs
- My Jobs
- Edit Jobs
- Delete Jobs
- View Applicants
- Update Application Status
- Email Notifications

### Admin
- Admin Dashboard
- View Users
- View Jobs
- Delete Users
- Delete Jobs

## Technologies

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript
- Werkzeug
- Gmail SMTP

## Database

Database name:

`jobportal`

Tables:

- users
- jobs
- applications
- profiles
- saved_jobs
- password_resets
